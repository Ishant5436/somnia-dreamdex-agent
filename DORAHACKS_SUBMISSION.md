## Project Description
`somnia-dreamdex-agent` is an autonomous AI agent gateway and high-throughput EVM router for DreamDEX Event Contracts on the Somnia Layer-1 blockchain. 

By combining real-time Parkinson realized volatility estimation with deterministic safety invariants and non-reentrant smart contract routing, the agent eliminates 90%+ of bad-fill losses in choppy regimes while executing high-probability binary event contracts with sub-second finality.
